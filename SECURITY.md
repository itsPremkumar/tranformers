# Security Policy

## Supported Versions

Currently, the latest version of the Transformer Robot project is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of our modular robotics platform seriously. If you find a vulnerability, please do NOT open a public issue. Instead, please follow these steps:

1. Send an email to the project maintainer (see profile).
2. Provide a detailed description of the vulnerability and steps to reproduce it.
3. Allow us up to 48 hours to acknowledge your report.

We will coordinate a fix and a public disclosure once the issue is resolved.
