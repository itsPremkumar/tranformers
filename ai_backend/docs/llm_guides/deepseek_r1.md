# 🧠 DeepSeek R1 (The Reasoning Brain)

## Overview
DeepSeek R1 is the high-end "Thinker" model. It is designed for tasks that require deep logic, mathematical precision, and chain-of-thought processing.

## Key Capabilities
*   **Logical Prowess**: Solves puzzles and complex navigation logic far better than standard chat models.
*   **Instruction Following**: Excellent at strictly adhering to robot command formats (JSON).
*   **Chain-of-Thought (CoT)**: You can see the robot "thinking" through steps before it acts.

## Configuration in `.env`
```bash
# Set as fallback if deep logic is needed
OLLAMA_MODEL="deepseek-r1" 
```

## Best Use Cases
*   Complex robot programming (e.g., "Script a dance sequence using existing commands").
*   Strategic decision making (e.g., "Decide which room to patrol first based on battery levels").
*   Technical Q&A and coding help.
