# 🐎 Llama 4 Maverick (The All-Rounder)

## Overview
Llama 4 Maverick is Meta's flagship Mixture-of-Experts (MoE) model. It is the most balanced high-end open model for both persona and control.

## Key Capabilities
*   **Persona Fidelity**: Best at maintaining the "Omni-Core" character voice with wisdom and authority.
*   **Context Window**: Supports massive context, allowing the robot to remember thousands of words of recent history.
*   **Tool Use**: Extremely reliable at triggering the robot's physical tools (Motors, Gimbal, Web Search).

## Configuration in `.env`
```bash
OLLAMA_MODEL="llama4:maverick"
```

## Best Use Cases
*   Daily companionship and conversation.
*   General robot control and home automation.
*   Multi-robot fleet management.
