# Contributing to Transformer Robot

First off, thanks for taking the time to contribute! This project aims to bring the concept of real-life Transformers to reality, and every bit of help is appreciated.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issue Tracker.
- Describe the bug and include steps to reproduce.
- Mention your hardware configuration (ESP32 version, servo models, etc.).

### Suggesting Enhancements
- Explain why the enhancement would be useful.
- Provide examples or pseudo-code if possible.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the documentation is updated if you change functionality.
4. Issue a pull request!

## Coding Standards
- **Python**: Follow PEP 8.
- **C++ (Arduino/PlatformIO)**: Use consistent indentation and clear variable names.
- **Documentation**: Keep the `docs/` folder updated with any structural changes.

## Safety First
This project involves moving parts and high-discharge batteries (LiPo). Always prioritize safety:
- Never test high-torque servos near your face.
- Use a fuse in your power distribution.
- Document any potential hazards you find.
